# Liquid Glass JS

Repository:
https://github.com/dashersw/liquid-glass-js

Use Liquid Glass for glass-like refractive interface elements.

Good use cases:

- navigation
- floating buttons
- control panels
- cards
- overlays

Avoid applying the effect to every surface.

Before implementation:

1. Check the current package API.
2. Check browser compatibility.
3. Provide a graceful CSS fallback.
4. Test mobile performance.

Glass effects must not make text difficult to read.

Maintain sufficient contrast and accessibility.
